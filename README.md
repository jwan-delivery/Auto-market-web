# الملهلب — سوق السيارات السوداني

واجهة عربية RTL لعرض عروض السيارات، بهوية سوداء وبيضاء مع خيار أصفر، وتصميم زجاجي متجاوب مع الهاتف.

## الموجود في الواجهة الحالية
- موجز بسيط قريب من أسلوب المنشورات.
- فلاتر للنوع والماركة والسعر والولاية وسنة التصنيع واللون ونوع المستند وولاية الترخيص.
- نموذج إضافة وتعديل، وصف يُنشأ من البيانات، رقم عرض، حالة «تم البيع»، مشاركة وروابط اتصال وواتساب.
- وضع معاينة مدير محلي للتجربة فقط.

## مهم قبل الاستخدام الحقيقي
هذه نسخة واجهة/معاينة. الإعلانات تحفظ في LocalStorage على الجهاز نفسه. زر «فتح لوحة المعاينة» ليس تسجيل دخول آمناً، ولا يصلح لإدارة إعلانات حقيقية. لم يتم توصيل واجهة التطبيق بقاعدة Supabase بعد، ولم يتم التحقق من نشر إنتاجي على Vercel.

## ربط قاعدة البيانات
1. افتح مشروع Supabase.
2. من SQL Editor شغّل الملف supabase-schema.sql.
3. أنشئ حساب المدير من Authentication، ثم أضف ملفه في public.profiles واجعل role='admin' باستخدام UUID الحقيقي.
4. لا تضع service_role key في المتصفح أبداً. استخدم المفتاح العام فقط بعد مراجعة سياسات RLS.
5. يلزم توصيل عميل Supabase في app.js واستبدال التخزين المحلي بعمليات القراءة والإضافة والتعديل والحذف.
6. لإنشاء تخزين الصور، أنشئ bucket باسم car-images بسياسات مناسبة. لا تعتمد على Base64 في LocalStorage.

## قبل الإطلاق العام
- تفعيل Supabase Auth وتقييد لوحة المدير.
- توصيل Storage للصور.
- اختبار سياسات RLS بحساب مستخدم عادي وحساب مدير.
- استبدال السيارات التجريبية بإعلانات حقيقية وإضافة أرقام التواصل.
- اختبار الهاتف وواتساب والبحث على Android.
- التحقق من deployment الإنتاجي والنطاق.
