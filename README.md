# الملهلب — سوق السيارات السوداني

واجهة عربية RTL لعرض السيارات بهوية سوداء وبيضاء مع خيار أصفر، وتصميم زجاجي مناسب للهاتف.

## ما تم ربطه في الكود
- Supabase Auth لتسجيل الدخول وإنشاء حساب مستخدم حقيقي؛ لا يوجد زر «مدير تجريبي».
- جدول `cars` في Supabase لقراءة الإعلانات المشتركة وإضافتها وتعديلها وتغيير حالة البيع وحذفها.
- Supabase Storage في bucket باسم `car-images` لرفع صور السيارات.
- صلاحيات RLS تمنح الزوار قراءة الإعلانات المنشورة فقط، وتمنح صلاحيات إدارة الإعلانات للمدير الذي يحمل `role = 'admin'` في جدول `profiles`.
- واجهة الهاتف والفلاتر والوصف التلقائي والاتصال وواتساب والمشاركة وتبديل الألوان باقية.

## خطوات التفعيل المطلوبة مرة واحدة
**الكود جاهز للاتصال، لكن لن يعمل الاتصال فعلياً قبل تنفيذ الخطوات الثلاث التالية:**

1. افتح [Supabase SQL Editor](https://supabase.com/dashboard/project/khgufiaxxitapbhxydaf/sql/new) وشغّل محتويات الملف `supabase-schema.sql`. هذا ينشئ الجداول والسياسات ومساحة صور `car-images`، ويجهّز إنشاء ملف مستخدم تلقائياً عند التسجيل.
2. افتح [مفاتيح مشروع Supabase](https://supabase.com/dashboard/project/khgufiaxxitapbhxydaf/settings/api-keys)، وانسخ **Publishable key** أو مفتاح `anon` العام القديم. افتح `supabase-config.js` في GitHub واستبدل النص `PASTE_SUPABASE_PUBLISHABLE_OR_ANON_KEY_HERE` بالمفتاح العام. هذا المفتاح مصمم للاستخدام بالمتصفح؛ لا تضع مطلقاً مفتاح `service_role` أو أي Secret في هذا الملف.
3. افتح الموقع وأنشئ حساباً من «دخول / حساب»، ثم أكّد البريد إذا طلب منك ذلك. ارجع إلى SQL Editor ونفّذ الأمر التالي بعد استبدال البريد ببريد حسابك الحقيقي:
   ```sql
   insert into public.profiles (id, display_name, role)
   select id, 'الملهلب', 'admin'
   from auth.users
   where email = 'YOUR_EMAIL@example.com'
   on conflict (id) do update set role = 'admin';
   ```
   يجب أن يغيّر الأمر صفاً واحداً. سجّل الخروج ثم الدخول من الموقع؛ ستظهر صلاحيات إدارة الإعلانات لحساب المدير. جميع الحسابات الجديدة تبدأ بصلاحية مستخدم عادي.

## النشر على Vercel
الموقع ثابت (HTML/CSS/JavaScript) ولا يحتاج إلى أمر build. اربط مستودع [Auto-market-web](https://github.com/jwan-delivery/Auto-market-web) بمشروع Vercel على الفرع `main` ليُنشَر كل commit تلقائياً. لم أتمكن من رؤية أي مشروع Vercel ضمن الاتصال المتاح لهذه الجلسة؛ لذلك لا أستطيع تأكيد أن الربط أو النشر الإنتاجي اكتمل. بعد تحديث `supabase-config.js` تحقّق من آخر Deployment وأن الحالة Ready، ثم افتح رابط الموقع واختبر التسجيل والإعلانات والصور.

## الأمان والتكاليف
- لا يوجد تسجيل دخول مدير تجريبي محلي.
- لا تُمنح صلاحيات المدير بمجرد التسجيل؛ تغيير الدور يتم من SQL Editor فقط.
- سياسات RLS تحمي الجداول، وسياسات Storage تقصر الرفع والتعديل والحذف على المدير.
- المفتاح العام ليس سرّاً، لكن سياسات RLS هي التي تحمي البيانات. لا تشارك كلمة مرور المدير أو أي مفاتيح سرية.
- إعدادات التخزين وحدود الاستخدام تعتمد على خطة Supabase الفعلية؛ راجع الاستخدام في لوحة المشروع ولا تفترض أن تخزين الصور بلا حدود.
